# 🚀 Portafolio Interactivo de Nahir

> **Perfil:** Estudiante de Programación &bull; Pensamiento Lógico &bull; Futura Ingeniera en Sistemas &bull; Ciberseguridad

Este portafolio web interactivo fue diseñado y programado a tu medida a partir de tus respuestas, con una estética **Cyber-Security / Modern Dark Mode** y un alto nivel de dinamismo para impresionar a profesores, compañeros o reclutadores desde el primer segundo.

---

## ⚡ Características Implementadas

1. **Terminal CLI Interactiva:**
   - Permite escribir comandos reales como `help`, `about`, `skills`, `goals`, `roadmap`, `matrix`, `projects` y `clear`.
   - Incluye botones de acceso rápido para que cualquier usuario pueda interactuar incluso desde un celular.
2. **Simulador de Intérprete Python en Vivo:**
   - Permite ejecutar un algoritmo de lógica y ver la salida formateada en una consola interactiva.
3. **Módulo de Ciberseguridad (Cifrador Dinámico):**
   - Herramienta en vivo donde el visitante escribe cualquier texto, ajusta una clave de desplazamiento y ve el cifrado en tiempo real junto con un hash simulado.
4. **Roadmap de Formación Técnica:**
   - Desde los fundamentos iniciales (Scratch y lógica algorítmica), el aprendizaje actual en Python, hasta la meta de Ingeniería en Sistemas y Ciberseguridad.
5. **Repositorio Modular de Proyectos:**
   - Tarjetas de proyectos (Python, Scratch, **Identidad Visual & Logo Empresarial** con visor en alta resolución) y ranuras modulares listas para futuros módulos.
6. **Efecto Lluvia de Código Matrix (Canvas):**
   - Fondo animado de partículas de código con botón para pausar o activar.
7. **Formulario de Transmisión / Contacto:**
   - Con respuesta visual interactiva estilo terminal.

## ✏️ Cómo Agregar tus Futuros Proyectos

Abre el archivo `index.html` con cualquier editor de texto o código (como VS Code o el Bloc de Notas) y busca la sección comentada:

```html
<!-- ================= SECCIÓN PROYECTOS / SHOWCASE MODULAR ================= -->
```

Allí encontrarás tarjetas como esta:

```html
<!-- PROYECTO 4: PLACEHOLDER 2 -->
<div class="rounded-xl border border-dashed border-slate-700 ...">
    ...
    <h3 class="text-lg font-bold text-slate-300">
        [Mi Próximo Proyecto de Curso]
    </h3>
    <p class="text-slate-500 text-xs sm:text-sm mt-2">
        Descripción de lo que hace tu programa en Python...
    </p>
</div>
```

Solo cambia el título, las etiquetas de tecnologías y la descripción por las de tu proyecto cuando lo termines.

## 🌐 Cómo Publicarlo en Internet Gratis (GitHub Pages)

Cuando quieras tener un enlace público (ejemplo: `nahir.github.io/portfolio`) para compartirlo con tu profesor o amigos:
1. Crea una cuenta gratuita en [GitHub](https://github.com/).
2. Crea un nuevo repositorio público llamado `mi-portafolio`.
3. Sube los archivos `index.html`, `style.css` y `script.js`.
4. Ve a **Settings > Pages** en GitHub, selecciona la rama `main` y guarda.
5. ¡Listo! Tu portafolio estará online y disponible en todo el mundo.
